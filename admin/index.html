Landers On Tour Admin — just you

Add memories, update itineraries, or start a new trip. This page talks straight to GitHub — nothing runs on a server, and only someone with your access token can save changes here.

1Connect

Paste your GitHub token below. It's saved only in this browser (never sent anywhere but GitHub) so you'll only need to do this once per device. See the README for how to create one — takes two minutes.

2Add a memory

A quick update, a caption, and optionally a link to a Google Photos album. Get a shareable link in Google Photos: open the album → Share → Create link, then paste it below.

Google Photos won't let us embed the album itself, so this renders as a tap-through gallery card on the trip page — a link is "anyone who has it can view," same as clicking through, so there's no extra exposure either way.

3Add an itinerary entry

Adds a new day block to an existing trip. One line per stop, formatted as TIME | what happens.

4Start a new trip

Upload a trip PDF (a confirmation packet, a run-of-show, whatever you've got) and this will pull out a title, dates, and a day-by-day itinerary to get you started. It's a text-pattern reader, not magic — always check its work below before creating the trip.

5Edit a page directly

For when plans change and the itinerary on the page no longer matches what actually happened. This loads the trip's full page source, front matter and all the HTML below it, so you can edit or delete anything by hand, then saves it straight back.
